# 观影手记 · 你的私人电影日记

一个手机浏览器里打开、能「加到主屏幕当 App 用」的电影记录网页。纯前端、无后端、数据全存在你自己的设备里。

## ✨ 功能

- **添加电影**：首页搜索栏搜片名 → 选观影时间 → 进电影库（也可手动添加）
- **按次记录**：同一部电影支持**二刷、三刷**，每次都有独立的心得 / 台词 / 评论 / 截图，并自动标注「首刷 / 二刷 / 三刷」
- **四个分栏**：观影感受、喜欢的台词、最美定格（截图+每图评论+标「最美画面」）、评论区（评分+短评）
- **标签与分类**：类型 / 心情 / 年份，可多选、可新建
- **自动搜资料**：填了 TMDB 密钥后，输入片名可自动拉海报、简介、导演、演员（拉不到就手动填）
- **观看统计**：今年看了多少部、平均分、**观影偏好**（各类型看了多少）、按月趋势、评分分布、二刷了几部
- **搜索与筛选**：按片名 / 时间 / 评分 / 标签快速找
- **数据备份**：一键导出 / 导入 JSON，零配置

## 🔒 关于隐私（很重要）

- 你记录的所有电影、心得、截图，**只存在你手机/电脑浏览器的本地存储（IndexedDB）里，永远不会上传到任何服务器**。
- 部署到 GitHub Pages，只是把**应用的代码**（HTML/CSS/JS）放到一个网址上，方便你用手机打开。代码里没有任何你的个人数据。
- 因此「仓库是公开还是私有」只影响**源代码**是否可见，不影响你的观影数据——数据本来就在你本地。

## 🚀 部署到 GitHub Pages

> 前提：你有一个免费 GitHub 账号（没有的话去 github.com 注册，几分钟搞定）。

### 两种仓库选择（请先看清区别）

| 方式 | 仓库可见性 | 花费 | 站点网址 | 说明 |
|------|-----------|------|----------|------|
| **A. 公开仓库** | 公开 | 免费 | 公开网址 | 推荐。代码公开但**不含你的数据**，最省事 |
| **B. 私人仓库** | 私有 | 需 GitHub Pro（$4/月） | 公开网址 | 源代码保密；但**站点网址本身仍是公开的**（任何拿到链接的人都能打开 app，只是看不到代码）。免费版 GitHub **不支持**私人仓库开 Pages |

> 简单说：免费账户只能给「公开仓库」开 Pages。如果你坚持私人仓库，需要先升级到 GitHub Pro（$4/月）。无论哪种，你的观影数据都在本地，不会泄露。

### 方式一：用 GitHub Desktop（最省心，但需下载安装软件）

> 如果不想下载任何软件，请直接用**方式二（纯网页上传）**。

1. 下载安装 [GitHub Desktop](https://desktop.github.com/)。
2. 在 GitHub 网页新建仓库：点右上角 `+` → 新建仓库 → 填名字（如 `movie-diary`）→ 选 **公开** 或 **私有** → 不要勾选 添加 README → 创建仓库。
3. 在仓库页面点 **「…」或 代码 → 用 GitHub Desktop 打开**，把仓库克隆到电脑。
4. 把本项目**整个文件夹**（`index.html`、`css/`、`js/`、`assets/`、`manifest.webmanifest`、`.nojekyll`）复制进克隆下来的仓库文件夹。
5. GitHub Desktop 会自动列出改动 → 填个摘要（如「初版观影手记」）→ 点 **提交到 main** → 点 **推送到 origin**。
6. 在 GitHub 网页进入该仓库 → **设置 → 页面** → 来源 选 **从分支部署** → 分支 选 `main`、目录选 `/(根目录)` → 保存。
7. 等一两分钟，访问 `https://你的用户名.github.io/movie-diary/` 即可。

### 方式二：纯网页上传（不用装软件，推荐不想下载的用户）

1. 在 GitHub 网页右上角 `+` → **新建仓库** → 名称填 `movie-diary` → 可见性选 **公开** → 下方「添加 README / .gitignore / 许可证」都**不要勾** → 创建仓库。
2. 进入空仓库 → 点 **添加文件 → 上传文件** → 进入上传界面。
3. **把 `D:/工作空间/movie-diary` 文件夹里面的所有内容**（`index.html`、`css/`、`js/`、`assets/`、`manifest.webmanifest`、`.nojekyll`）一起拖进上传框。
   - ⚠️ 拖的是**文件夹里面的内容**，不是 `movie-diary` 这个文件夹本身——否则网址会多套一层 `movie-diary/`，打不开。
   - 隐藏文件 `.nojekyll` 没传上去也没关系（本项目文件名没有下划线开头的，不需要它）；想补可在仓库里「添加文件 → 创建新文件」建一个空文件名叫 `.nojekyll`。
4. 点 **提交更改（Commit changes）**。
5. 进入仓库 **设置 → 页面（Pages）** → 源 选 **从分支部署** → 分支 选 `main`、目录 `/(根目录)` → 保存。
6. 等一两分钟，访问 `https://你的用户名.github.io/movie-diary/` 即可。

> 提示：网页上传请务必用「拖拽整个文件夹内的内容」的方式，让 GitHub 自己保留 `css/`、`js/`、`assets/` 的子目录结构；用「选用你的文件」逐个选会丢失目录。

### 手机上使用（加到主屏幕，像 App 一样）

1. 手机浏览器（Safari / Chrome）打开上面的网址。
2. 点浏览器的「分享」→「添加到主屏幕」（iOS 在底部工具栏，安卓在菜单里）。
3. 桌面就会出现「观影手记」图标，点开即用，还能离线打开。

## 💡 其他说明

- **TMDB 密钥（可选）**：想要「搜片名自动填资料」才需要。注册 themoviedb.org → 设置 → API → 复制 v3 key，在 app 内「设置」里粘贴保存。没有也能用，只是要手动填。
- **定期备份**：在 app「设置」里点「导出备份」，把 JSON 存好。换手机/清缓存前务必备份。
- **本地预览（不部署也能看）**：电脑上用浏览器打开 `index.html` 即可（部分浏览器在 `file://` 下不允许 Service Worker，属正常，不影响记录功能）。
- **项目结构**：
  - `index.html` 入口
  - `css/style.css` 浅蓝浅绿简洁主题
  - `js/db.js` 本地数据库（IndexedDB）
  - `js/util.js` 工具（含多刷次逻辑）
  - `js/views/` 各页面（列表 / 详情 / 编辑 / 统计 / 设置）
  - `js/tmdb.js` 电影资料搜索
  - `manifest.webmanifest` + `assets/` PWA 图标
